# 冯子贤个人主页

纯 HTML、CSS、JavaScript 实现的个人主页，无构建步骤和运行时第三方依赖。

## 本地预览

在本目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。
